# FamilyWheel — Семейный персонализированный руль

**Проблема**  
Дети могут случайно «завести» автомобиль. Угоныщики тоже могут. Руль нужно защищать.

**Решение**  
**FamilyWheel** — интеллектуальный руль с защитой для детей и угонщиков:  
- адаптируется под каждого ребёнка  
- блокирует поворот при «детском хвате»  
- даёт полную свободу взрослому  
- реагирует на угонщика голосом из «Долларовой трилогии»  
- интегрируется с Speech Editor и Parent Voice

**Главная функция — ChildPressureLock**  
Запоминает индивидуальный порог силы (2–5 кг).  
При «детском хвате» руль полностью блокирует поворот.  
Взрослый снимает блокировку одним касанием телефона.  
AI отличает «это мой сын» от «это чужой» по отпечатку руки.

**Режим «Угонщик» (Sternfänger / Человек без имени)**  
Голос из **«Долларовой трилогии»** («Хороший, плохой, злой»):

- Для угонщика:  
  «Эй, ты, говнюк!»  
  (Звуки выстрелов из револьвера)

- Для детей (если завели и они в салоне):  
  «Эй, вы, маленькие говнюки!»  
  «Заворачивайте обратно!»  
  + звуки выстрелов

**Как это сработает**  
AI распознаёт угрозу (незарегистрированный человек + необычное поведение)  
• Руль блокируется полностью (ChildPressureLock)  
• Авто говорит голосом через колонки  
• На дисплее — большая красная надпись «УГОН!»

**Как это выглядит**

[Родитель]          [Ребёнок пытается завести / Угонщик] |                           | Полный контроль + ключ              Датчик силы нажатия + микрофон |                           | Блокировка руля                 (stretchable pressure sensor) |                           | [AI FamilyWheel]          Разрешение только по отпечатку / ключу |                           | [Система безопасности]      Блокировка поворот < порога + режим Угонщик |                           | Интеграция с Speech Editor     Идентификация ребёнка |                           | (Parent Voice)          Запоминание предпочтений

**Редактор речи для позднооглохших**  
FamilyWheel отлично дополняет **Редактор речи** (Speech Editor).  
Когда человек за рулём — ChildPressureLock запоминает его индивидуальный порог силы и **не блокирует** руль случайно.  
Система реагирует только на необычное поведение или попытку завести авто.  
Голос из «Долларовой трилогии» можно использовать как пример — потом легко заменить на любой другой (включая синтезированный или от актёра).

**Техническая основа**  
- Stretchable pressure sensors (аналог FORCIOT)  
- AI-модуль для распознавания ребёнка  
- Электромагнитный или механический фиксатор руля  
- Микрофон + TTS для голоса  
- Звук выстрелов — бесплатный эффект (revolutionary.wav)

**Преимущества**  
✅ Полная безопасность в машину  
✅ Интегрируется с Speech Editor и Parent Voice  
✅ Уникально в связке с остальными проектами  
✅ Защита от угонщиков тоже

**Почему это не ново**  
Есть Teen Driver (только лимиты скорости), патенты с датчиками давления.  
Но нет комбинации: сила + распознавание ребёнка + блокировка поворота + Speech Editor + режим «Угонщик» с голосом из «Долларовой трилогии».
